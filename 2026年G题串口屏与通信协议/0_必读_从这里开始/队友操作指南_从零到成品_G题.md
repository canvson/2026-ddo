# 队友操作指南：从零到可用串口屏

## 1. 先生成底图

```powershell
python tools/generate_g_assets.py
```

导入 `assets/page0_overview_g.jpg`、`assets/page1_wave_g.jpg`、`assets/page2_spectrum_g.jpg`。

## 2. 只建 3 页

| 页面 | 内容 |
|---|---|
| `page0` | 总览参数 |
| `page1` | 波形 |
| `page2` | 频谱 |

不用做独立异常页、设置页、结果页。状态由 STM32 在当前页覆盖。

## 3. 建透明热区

按 `2_串口屏工程/HMI编辑器操作清单_G题.md` 建热区：

- page0：底部 `波形`、`频谱`。
- page1：`1周期`、`3周期`、底部 `参数`、`频谱`。
- page2：底部 `参数`、`波形`。

不要在 page0 做 `UA/UB/UB+uJ` 三选一按钮。这个模式由 FPGA 板上按键选择，屏幕只显示 FPGA 上报的当前模式。

## 4. 贴事件脚本

复制 `2_串口屏工程/HMI事件脚本_G题.md` 中对应脚本。

必须发送的帧只有：

| 操作 | 帧 |
|---|---|
| 1 周期 | `AA 31 01 01 DD 55` |
| 3 周期 | `AA 31 01 03 DF 55` |
| 参数页 | `AA 32 01 00 DD 55` |
| 波形页 | `AA 32 01 01 DE 55` |
| 频谱页 | `AA 32 01 02 DF 55` |

## 5. 编译和下载

HMI 编辑器里检查：

- 图片分辨率为 `1024x600`。
- 热区坐标没有偏移。
- 编译 `0错误、0警告`。
- 下载后触摸底部导航能切页。
- page1 点 `1周期/3周期` 能本地高亮，并通过串口发对应 HEX。

## 6. 和 STM32 联调

联调顺序：

1. 不接 FPGA，只用串口助手给 STM32 发 HMI 测试帧，确认切页/周期有效。
2. 接 FPGA 或 PC 仿真器，让 STM32 收到 `FEATURE`。
3. page0 应刷新模式、状态、Vpp、Urms、f1、分量。
4. page1 应按分量和相位合成波形；多分量 `FEATURE` 必须带 `phase_valid=1`，否则页面只显示 `PHASE REQUIRED`，不画伪造曲线。
5. page2 应画 1~3 根线谱。

验收时，屏幕同学只需要确认 UI 和触摸帧正确；算法模式和测量数据由 FPGA/STM32 负责。
