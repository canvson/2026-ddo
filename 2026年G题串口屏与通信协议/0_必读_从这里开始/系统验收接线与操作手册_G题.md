# 系统验收接线与操作手册

## 1. 接线

建议对外只暴露一个被测输入 BNC。评测信号接入 FPGA 外置 ADC 板，FPGA 持续采样并通过板上按键选择当前算法模式。

| 模块 | 连接 |
|---|---|
| 信号源 | BNC -> FPGA 外置 ADC 输入 |
| FPGA -> STM32 | UART，`A5 5A ... crc16`，默认 `921600 8N1` |
| STM32 <-> 串口屏 | `115200 8N1`；HMI 上行 `AA CMD ... 55`，STM32 下行 TJC 原生命令 |
| 串口屏供电 | 按屏幕模块要求独立供电并共地 |

## 2. 上电检查

1. 串口屏显示 `page0` 参数页。
2. 状态栏初始为 `等待数据`。
3. FPGA 输出 `FEATURE` 后，page0 顶部 `FPGA模式` 应显示 `UA/UB/UB+uJ`。
4. page0 的 Vpp、Urms、f1 和 C1~C3 分量随数据刷新。

## 3. UA 模式

1. 在 FPGA 板上选择 `UA` 算法。
2. 向输入端接入题目规定范围内的周期信号。
3. 观察 page0 参数。
4. 切到 page1，分别点 `1周期` 和 `3周期`，确认横向周期数变化。
5. 切到 page2，确认只显示基波和谐波线谱。

## 4. UB 模式

1. 在 FPGA 板上选择 `UB` 算法。
2. 输入分量最高可到 500kHz 的测试信号。
3. 观察 page2 线谱位置，100k、200k、300k、400k、500k 刻度应和网格对齐。
4. 参数页分量幅值按峰值 mV 显示。

## 5. UB_J 模式

1. 在 FPGA 板上选择 `UB_J` 算法。
2. 输入包含 `uJ` 干扰的信号。
3. page0 模式显示 `UB+uJ`。
4. 如果 `flags.interference_suppressed=1`，状态或说明区可提示干扰已抑制。
5. page1/page2 显示抑制干扰后的 `UB` 结果，不显示 1MHz 以上干扰频线。

## 6. 波形真实性专项检查

1. FPGA 发送两个或三个分量时必须置 `flags.bit1=phase_valid`，并填写各分量 `phase_deg10`。
2. 故意发送 `component_count>1、phase_valid=0`：page0/page2 可继续显示参数和线谱，page1 必须显示 `PHASE REQUIRED` 且没有绿色合成曲线。
3. 单分量缺相位时允许使用 0 度时间参考，波形形状不受影响。
4. 用 `f1=10kHz、最高分量=500kHz、3 周期` 做极限检查；STM32 应按 601 点绘制，实屏不得退化成低频伪波形或出现队列溢出。

## 7. 状态判断

| 屏幕状态 | 含义 | 处理 |
|---|---|---|
| `等待数据` | 尚无合法 `FEATURE` | 检查 FPGA 串口和包格式 |
| `实时` | 最新特征有效 | 正常观察 |
| `数据保持` | 新特征超时，保留旧值 | 检查 FPGA 是否仍在发送 |
| `通信异常` | 长时间无有效 FPGA 帧 | 检查接线、波特率、共地 |
| `CRC错误` | 校验错误持续出现 | 检查线序、波特率、噪声 |
| `超量程` | FPGA 上报输入超限 | 降低输入幅度 |
| `算法异常` | FPGA 上报算法或链路内部错误 | 看 STM32 调试串口统计 |

## 8. 现场建议

- 串口屏不作为测量触发入口，避免评测时多一步人工操作。
- 切页不影响 FPGA 算法，评委可随时看参数、波形、频谱。
- 若现场被问到“按键控制”，说明 FPGA 板上按键控制算法模式，串口屏虚拟键用于显示选择。
