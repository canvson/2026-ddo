# 2026 G 题串口屏资料包说明

本资料包面向 2026 G 题“周期信号测量分析装置”。当前方案采用 FPGA 主导测量：信号接入 FPGA 外置 ADC 后，FPGA 板上按键选择 `UA/UB/UB_J` 算法并持续发送 60 字节 `FEATURE` 特征包；STM32 被动接收特征数据，负责分析缓存、波形合成、线谱绘制和串口屏刷新。

串口屏只保留两类操作：

| 操作 | 作用 |
|---|---|
| 页面切换 | 在参数、波形、频谱 3 页之间切换。 |
| `1周期/3周期` | 只改变 STM32 波形页横轴显示窗口，不影响 FPGA 算法状态。 |

## 关键结论

- 题目问答确认：Vpp 是整体合成波形峰峰值，不是单个分量。
- 题目问答确认：频谱分量幅值按峰值显示，页面标签写成峰值 mV。
- 频谱是离散线谱，不显示相位数值；但只要 `component_count>1`，FPGA 就必须置 `phase_valid=1` 并传各分量相对相位，STM32 才合成波形。
- 多分量缺相位时参数/频谱仍刷新，波形页显示 `PHASE REQUIRED`，绝不按全 0 相位伪造曲线。单分量可用 0 度时间参考。
- 当前协议不传原始/抽取波形点。波形点方案若启用，必须另行扩展协议版本和包类型。
- 波形绘图点数按 `f_max/f1` 自适应；`10kHz` 基波、`500kHz` 分量、3 周期使用 601 点。
- 输入频率为 500Hz 整数倍，最多基波加 2 个谐波，分量最高不超过 500kHz。
- `UB_J` 页面显示 FPGA 已抑制干扰后的 `UB` 结果，不显示 1MHz 以上干扰频线。
