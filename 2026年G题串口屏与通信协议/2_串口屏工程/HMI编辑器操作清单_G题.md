# HMI 编辑器操作清单

目标：用现有 `.HMI` 模板复现 3 页被动显示界面。只做页面切换和周期选择，测量数据全部由 STM32 回写。

## 1. 生成底图

在资料包根目录运行：

```powershell
python tools/generate_g_assets.py
```

确认 `assets/` 中只有：

- `page0_overview_g.png/.jpg`
- `page1_wave_g.png/.jpg`
- `page2_spectrum_g.png/.jpg`

## 2. 页面

保留或新建 3 页：

| 页面 | 背景图 |
|---|---|
| `page0` | `page0_overview_g.jpg` |
| `page1` | `page1_wave_g.jpg` |
| `page2` | `page2_spectrum_g.jpg` |

不用创建独立异常页、联调页、结果页。异常文本由 STM32 覆盖当前页状态栏。

## 3. 字体与颜色

- 字体 ID1：普通动态字段与状态，使用现有 `ID1.zi` 或项目已有中文字体。
- 字体 ID2：新增 16 像素字库，供 page2 的频率/幅值两行文本使用；HMI 工程中的实际字体编号必须为 2。
- 字体 ID3：可新增 8 像素字库作为预留，本版评测主数据不调用。
- 文字覆盖区域尽量使用等宽或较粗字体。
- STM32 动态值用 `xstr` 覆盖，背景色与底图字段框一致。

字模必须在 HMI 编辑器中导入并编译进工程。串口命令只能引用字体 ID，不能临时生成或缩放字库。

常用 RGB565：

| 名称 | 值 |
|---|---:|
| 白色 | `65535` |
| 面板 | `6471` |
| 字段框 | `8617` |
| 蓝色 | `11263` |
| 绿色 | `11564` |
| 黄色 | `62951` |
| 红色 | `55882` |

### page2

| 控件名 | 坐标 | 脚本 |

热区背景透明，文字和按钮外观留在底图里。page1 周期按钮可用脚本本地高亮，STM32 收到后也会覆盖右侧“周期”字段并重画波形。

## 5. 动态覆盖区域

按 `../1_硬件与协议文档/动态刷新字段清单_G题.md` 建立 STM32 覆盖坐标。重点：

- page0 模式和状态在顶部宽框，参数和分量值都有较大覆盖区域。
- page1 绘图区由 STM32 清屏再画线；右侧数值框不要放固定数值控件。
- page1 绘图区必须允许 STM32 在多分量缺相位时覆盖显示 `PHASE REQUIRED`；不需要额外 HMI 控件，该提示由 `xstr` 动态绘制。
- page2 底图不画频线，频谱线全由 STM32 画。
- page2 标题“分量与状态”位于右栏顶部，C1 第一行从 `y=172` 开始，两者之间必须保留间距。
- page2 的静态 `C1/C2/C3` 不在动态字符串中重复。STM32 用字体 ID2 在 `y=172/252/332` 分别发送频率和幅值两行。

## 6. 编译检查

HMI 编辑器目标：`0错误、0警告`。如果页面图片过大，优先使用 `.jpg`；如果文字边缘不清晰，再切回 `.png`。

本资料包可以先验证底图和 STM32 串口命令；只有完成 ID2 字库导入、HMI 编译、生成可下载产物并在实屏检查三页触摸/文字/极限波形后，才算串口屏最终验收。仓库中的 `.HMI` 模板和 `.zi` 文件不等于已经完成实屏验收。
