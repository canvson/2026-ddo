波形绘制建议：

```text
清屏: fill 60,166,646,286,black
画线: line x0,y0,x1,y1,color
```

正式固件绘图规则：

```text
intervals = clamp(ceil(4 * periods * f_max / f1), 120, 646)
points = intervals + 1
```

- 多分量且 `phase_valid=0`：在绘图区中央 `258,306,250,42` 附近显示 `PHASE REQUIRED`，不发送绿色波形线。
- 单分量缺相位：允许以 0 度为时间参考。
- 极限 `10kHz/500kHz/3 周期` 使用 601 点。

右侧静态底图已经包含 `C1/C2/C3`，STM32 动态字符串不得重复这些标签。每个分量框发送两条 `xstr`：

```text
xstr 804,y,158,31,2,...,"50.000 kHz"
xstr 804,y+31,158,31,2,...,"90.0 mV"
y = 172 / 252 / 332
```

频谱线位置：

```text
x = 60 + freq_hz * 646 / 500000
base_y = 452
top_y = 452 - amp_peak_mv * 270 / max_peak_mv
```

底部刻度 `0/100k/200k/300k/400k/500k` 已对齐网格线，STM32 不需要重画刻度。

## 状态文本

推荐短文本：

| 文本 | 触发 |
|---|---|
| `WAIT DATA` | 尚无合法 `FEATURE`。 |
| `LIVE` | 最近 2 秒内有合法 `FEATURE`，且状态有效。 |
| `HOLD` | 超过 2 秒无新特征，保留上次值。 |
| `COMM ERR` | 超过 5 秒无有效 FPGA 帧。 |
| `CRC ERR` | 最近收到坏 CRC、特征已不新鲜，且尚无后续合法帧恢复。 |
| `OVER RANGE` | `FEATURE.status=3`。 |
| `ALGO ERR` | `FEATURE.status=4`。 |

三个页面必须使用同一个 STM32 运行状态结果。`STATUS` 持续到达而 `FEATURE` 停止时，2 秒后保持为 `HOLD`；只有连续 5 秒没有任何合法 FPGA 帧才显示 `COMM ERR`。

## 字体 ID

| ID | 用途 |
|---:|---|
| `1` | 普通数值、提示和状态。 |
| `2` | page2 分量两行值，16 像素字库，HMI 工程必须先加入。 |
| `3` | 预留 8 像素字库，本版评测主数据不使用。 |

STM32 的 `xstr` 只能选择已经编译进 HMI 工程的字体 ID，不能通过串口生成、缩放或替换字模。
