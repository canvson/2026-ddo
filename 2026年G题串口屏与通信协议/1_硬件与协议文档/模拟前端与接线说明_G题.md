# 模拟前端与接线说明

2026 G 题输入是信号源输出的周期信号 `u`，装置对外建议只保留一个 BNC 输入。`UA/UB/UB_J` 是 FPGA 板上选择的算法模式，不是三个物理输入口，也不是串口屏选择项。

## 输入链路建议

```text
BNC
  -> 50 欧姆端接
  -> 输入保护
  -> 交流耦合/中点偏置
  -> 固定增益或可校准增益
  -> 600kHz~700kHz 模拟低通
  -> 高速 ADC
  -> FPGA
```

## 关键指标

| 项目 | 建议 |
|---|---|
| 端接 | 50 欧姆到地，必要时跳帽可切换。 |
| 输入保护 | 小电容 ESD 或钳位，串 22~100 欧姆限流。 |
| 偏置 | 单电源 ADC 时偏置到 ADC 共模或约 1.65V。 |
| 增益 | 固定约 4 倍，并在 STM32/FPGA 侧预留校准系数。 |
| 模拟低通 | 截止约 600kHz~700kHz，避免高频干扰打满 ADC。 |
| ADC | 采样率不低于 10MSPS，分辨率不低于 12bit，优先并口。 |

## 三种 FPGA 模式

| 模式 | 输入含义 | 频率范围 | 幅度范围 |
|---|---|---|---|
| `UA` | `u=ua` | 10kHz~200kHz | 100mVpp~250mVpp |
| `UB` | `u=ub` | 10kHz~500kHz | 50mVpp~250mVpp |
| `UB_J` | `u=ub+uJ` | `ub`: 10kHz~500kHz；`uJ`: >=1MHz | `ub`: 50mVpp~250mVpp；`uJ`: 200mVpp |

## 接线

```text
信号源 OUT --BNC--> 装置 INPUT
信号源 GND -------- 装置 GND
装置 5V ----------- 单路 5V 电源
```

需要看模拟波形时，示波器可并到输入端或前端关键测试点。串口屏显示结果来自 FPGA 处理后的特征数据，不直接接信号源。

## 抗干扰注意

`UB_J` 模式中，1MHz 以上干扰幅度可达 200mVpp。如果 ADC 前级已经被干扰打满，数字滤波无法恢复真实 `ub`。因此前端要先避免过载，再由 FPGA 做数字滤波、峰值提取和 `FEATURE` 上报。
