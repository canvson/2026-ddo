# 双路波形输出串口屏工程

本目录是电赛赛前准备的串口屏模板工程，只处理 HMI 屏幕侧。STM32/FPGA 源码本次不在这里修改。

## 当前文件

| 文件 | 用途 |
|---|---|
| `双路波形控制.HMI` | USART HMI 编辑器工程，目标屏幕 `TJC1060X570_011`，分辨率 `1024x600` |
| `ID0.zi`、`ID1.zi` | 工程字库 |
| `asset/double_way_ctrl.2.jpg` | 单页参数设置背景图 |
| `tools/patch_hmi_program.py` | 检查或修正 `Program.s` 初始化 |
| `tools/build_dual_wave_hmi_frames.py` | 生成 `AA 21 16 ... CHECK 55` 联调 Hex 帧 |

## 核心约束

- 串口屏上电初始化：`baud=115200`、`recmod=0`、`bkcmd=0`。
- 调参过程不发业务帧。
- 只有“应用并输出”发送 `AA 21 16 ... CHECK 55`。
- STM32 使用 USART1 `115200 8N1`，DMA 接收。
