# 双路波形输出串口屏模板工程说明

本资料包用于电赛赛前可复用的双路波形输出控制链路：屏幕负责本地参数调节、按钮高亮和最终发帧；STM32 负责串口 DMA 接收、校验参数并换算 DDS 控制字；FPGA 负责双路 DDS 输出到 `DataA/DataB`。

## 页面定位

| 页面 | 用途 |
|---|---|
| `page0` | 唯一业务页：A/B 两路波形、频率、幅值、占空比，以及 B 相对 A 相位 |

不再保留 G 题原来的首页、学习页、结果页、错误页等业务页面。本模板的串口屏只做参数面板。

## 参数定义

| 参数 | 屏幕变量 | 范围 | 单位 |
|---|---|---:|---|
| A 路波形 | `a_wave` | 0 正弦，1 方波，2 三角 | 枚举 |
| B 路波形 | `b_wave` | 0 正弦，1 方波，2 三角 | 枚举 |
| A 路频率 | `a_freq` | 1~20000000 | Hz |
| B 路频率 | `b_freq` | 1~20000000 | Hz |
| A 路幅值 | `a_amp` | 0~5000 | mVpp |
| B 路幅值 | `b_amp` | 0~5000 | mVpp |
| A 路占空比 | `a_duty` | 10~90，5 步进 | % |
| B 路占空比 | `b_duty` | 10~90，5 步进 | % |
| B 相对 A 相位 | `b_phase` | -180~180 | deg |

相位约定：`b_phase > 0` 表示 B 滞后 A；`b_phase < 0` 表示 B 超前 A，也等价于 A 滞后 B。

## 通信原则

- 串口参数：`115200 8N1`。
- 屏幕只连接 STM32，不直接连接 FPGA。
- 调波形、调频、调幅、调占空比、调相位时只改 HMI 本地变量，不向 STM32 发业务帧。
- 只有点击“应用并输出”时，HMI 才发送一帧完整配置：`AA 21 16 ... CHECK 55`。
- STM32 必须使用 DMA 接收串口屏数据，并按 `通信协议_双路波形模板.md` 换算后下发 FPGA。

## 推荐操作顺序

1. 保存并关闭正在编辑的 `单页)双路波形控制屏/双路波形控制.HMI`，避免编辑器锁文件。
2. 确认 `.电赛预备/屏控波形输出串口屏部分/双路波形控制.HMI` 是最终要交付的 HMI 工程。
3. 在 USART HMI 编辑器中打开该 `.HMI` 文件，按 `HMI编辑器操作清单_双路波形模板.md` 添加/重命名控件。
4. 把 `HMI事件脚本_双路波形模板.md` 中的脚本粘贴到对应页面和按钮事件。
5. 编译 HMI，要求 `0错误、0警告`，导出 `.tft`。
6. 用串口助手或逻辑分析仪抓包：上电和调参过程不应出现业务帧，只有“应用并输出”出现 `AA 21 16` 帧。
7. STM32 侧按 DMA 接收说明接入解析器，并通过 USART2 向 FPGA 下发配置帧。
