# 从零配置串口屏操作指南

这份指南给队友使用，目标是把屏幕配置成“先本地调参数，最后点输出才发给 STM32”的双路波形控制面板。

## 第 1 步：准备工程

1. 打开 USART HMI 编辑器。
2. 打开 `111备赛串口屏/.电赛预备/屏控波形输出串口屏部分/双路波形控制.HMI`。
3. 确认屏幕型号为 `TJC1060X570_011`，分辨率 `1024x600`。
4. 确认工程编码为 `gb2312`。
5. 在 `Program.s` 中确认波特率是 `baud=115200`，并且没有 `printh 00 00 00 ff ff ff 88 ff ff ff` 这类上电输出。

## 第 2 步：确认页面

1. 页面列表中只保留或只使用 `page0`。
2. 页面背景使用 `asset/double_way_ctrl.2.jpg`。
3. 如果右侧属性里看到已有按钮 `b0` 到 `b32`，说明截图里的步进按钮已经在工程里。
4. 如果没有波形选择热区，手动添加 6 个透明按钮覆盖背景中的波形按钮。

## 第 3 步：添加本地数值控件

在 page0 上添加 7 个数字控件，用于保存和显示当前本地参数：

| 控件名 | 建议坐标 | 默认值 | 用途 |
|---|---|---:|---|
| `n_a_freq` | `110,220,140,51` | 1000 | A 频率 Hz |
| `n_a_amp` | `430,220,140,51` | 1000 | A 幅值 mVpp |
| `n_a_duty` | `745,220,140,51` | 50 | A 占空比 % |
| `n_b_freq` | `110,430,140,51` | 1000 | B 频率 Hz |
| `n_b_amp` | `430,430,140,51` | 1000 | B 幅值 mVpp |
| `n_b_duty` | `745,430,140,51` | 50 | B 占空比 % |
| `n_phase` | `452,521,110,58` | 0 | B 相对 A 相位 deg |

数字控件放在底图和按钮上层；如果盖住按钮文字，就稍微缩小宽度或移到输入框中间空白处。

## 第 4 步：配置波形互斥高亮

新增 6 个透明按钮：

| 控件名 | 建议坐标 | 弹起事件 |
|---|---|---|
| `a_sine` | `128,110,139,48` | `a_wave=0` 后粘贴 A 路高亮片段 |
| `a_square` | `282,110,139,48` | `a_wave=1` 后粘贴 A 路高亮片段 |
| `a_triangle` | `435,110,139,48` | `a_wave=2` 后粘贴 A 路高亮片段 |
| `b_sine` | `128,326,139,48` | `b_wave=0` 后粘贴 B 路高亮片段 |
| `b_square` | `282,326,139,48` | `b_wave=1` 后粘贴 B 路高亮片段 |
| `b_triangle` | `435,326,139,48` | `b_wave=2` 后粘贴 B 路高亮片段 |

A 路脚本只改 `a_wave`，B 路脚本只改 `b_wave`，两路互不影响。

## 第 5 步：配置参数按钮

当前工程已有的按钮编号按下表使用：

| 控件 | 功能 |
|---|---|
| `b0/b1` | A 频率 `-100/+100Hz` |
| `b10/b12` | A 频率 `-1K/+1K` |
| `b9/b11` | A 频率 `-10K/+10K` |
| `b6/b14` | A 频率 `-100K/+100K` |
| `b7/b13` | A 频率 `-1M/+1M` |
| `b3/b2` | A 幅值 `-100/+100mVpp` |
| `b5/b4` | A 占空比 `-5/+5%` |
| `b15/b8` | B 频率 `-100/+100Hz` |
| `b23/b25` | B 频率 `-1K/+1K` |
| `b22/b24` | B 频率 `-10K/+10K` |
| `b21/b27` | B 频率 `-100K/+100K` |
| `b20/b26` | B 频率 `-1M/+1M` |
| `b17/b16` | B 幅值 `-100/+100mVpp` |
| `b19/b18` | B 占空比 `-5/+5%` |
| `b28/b31` | 相位 `-5/+5deg` |
| `b29/b30` | 相位 `-10/+10deg` |
| `b32` | 应用并输出，唯一发送业务帧的按钮 |

频率按钮必须使用“先向下对齐，再加减”的脚本。例如当前频率是 `1Hz`，按 `+100Hz` 后应直接变成 `100Hz`。

## 第 6 步：配置输出按钮

`b32` 弹起事件必须执行三件事：

1. 从 `n_a_freq` 等数字控件同步本地变量。
2. 做边界限制：频率 `1~20000000Hz`，幅值 `0~5000mVpp`，占空比 `10~90%`，相位 `-180~180deg`。
3. 发送 `AA 21 16 ... CHECK 55` 完整配置帧。

其它按钮的弹起事件禁止出现 `printh AA` 或 `prints`，否则就会违反“调节过程不发送”的要求。

## 第 7 步：编译和下载

1. 点击编辑器编译。
2. 目标结果为 `0错误、0警告`。
3. 导出 `.tft`。
4. 通过 SD 卡或串口下载到屏幕。

## 第 8 步：不接 STM32 自检

1. 上电后停留在 `page0`。
2. 上电抓包不应出现 `AA 21`。
3. 点 A 路三个波形，只有 A 路一个高亮，B 路不变化。
4. 点 B 路三个波形，只有 B 路一个高亮，A 路不变化。
5. 把 A 频率设为 `1`，点 `+100`，应显示 `100`。
6. 把 B 频率设为 `1001`，点 `+1K`，应显示 `2000`。
7. 调幅、调占空比、调相位过程不应有串口业务帧。
8. 点“应用并输出”，才应出现一帧 `AA 21 16 ... 55`。
