# HMI 编辑器操作清单

本文按 USART HMI 编辑器里的实际操作顺序写。当前磁盘版工程已经有截图中的 `b0` 到 `b32` 按钮，但事件大多为空，需要按本清单粘贴脚本。

## 1. 打开工程

1. 关闭其它正在编辑同一个 `.HMI` 的窗口。
2. 打开 `111备赛串口屏/.电赛预备/屏控波形输出串口屏部分/双路波形控制.HMI`。
3. 确认 `Program.s` 中为 `baud=115200`、`bkcmd=0`。
4. 确认没有上电 `printh`。
5. 确认页面列表中至少有 `page0`。

如果要从截图里的源工程同步，先保存并关闭 `111备赛串口屏/单页)双路波形控制屏/双路波形控制.HMI`，再复制到 `.电赛预备/屏控波形输出串口屏部分/`。

## 3. 添加数字控件

新增 7 个数字控件：

| 控件名 | 坐标 | 默认值 |
|---|---|---:|
| `n_a_freq` | `110,220,140,51` | 1000 |
| `n_a_amp` | `430,220,140,51` | 1000 |
| `n_a_duty` | `745,220,140,51` | 50 |
| `n_b_freq` | `110,430,140,51` | 1000 |
| `n_b_amp` | `430,430,140,51` | 1000 |
| `n_b_duty` | `745,430,140,51` | 50 |
| `n_phase` | `452,521,110,58` | 0 |

建议属性：

- 字体：使用当前工程里清晰的中文/数字字体，本文脚本默认字体 ID `1`；如果只有字体 ID `0`，把脚本中 `xstr` 的第 5 个参数 `1` 改成 `0`。
- 背景色：与底图输入框接近，避免遮挡。
- 对齐：居中。
- 变量范围不靠控件属性保证，全部在事件脚本里限幅。

## 4. 添加波形触摸热区

背景图上已有波形按钮图案，但当前对象列表里没有对应触摸按钮。新增 6 个透明按钮：

|---|---|---|

| `a_square` | `282,110,139,48` | A 方波 |
| `a_triangle` | `435,110,139,48` | A 三角 |
| `b_sine` | `128,326,139,48` | B 正弦 |

如果用普通按钮代替透明按钮，需要把边框、背景和文字设置成透明或接近底图，否则会盖住原图。

## 5. 粘贴页面事件

在 `page0` 的“后初始化事件”中粘贴：

```text
n_a_freq.val=a_freq
n_a_amp.val=a_amp
n_a_duty.val=a_duty
n_b_freq.val=b_freq
n_b_amp.val=b_amp
n_b_duty.val=b_duty
n_phase.val=b_phase
```

然后继续粘贴 `HMI事件脚本_双路波形模板.md` 中的 “A 路波形高亮片段” 和 “B 路波形高亮片段”。

## 6. 粘贴按钮事件

- 所有按钮脚本都放在“弹起事件”，不要放“按下事件”。
- 除 `b32` 外，任何按钮事件里都不能出现 `printh AA`、`prints`。
- 每个频率按钮使用对应步长脚本，先对齐再加减。
- `b32` 粘贴“输出按钮完整脚本”。

## 7. 编译和导出

1. 点击“编译”。
2. 如果提示颜色变量不能用于 `fill/xstr`，把 `c_white`、`c_panel` 等变量换成对应十进制颜色值。
3. 编译必须达到 `0错误、0警告`。
4. 导出 `.tft`。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 上电 STM32 收到一串无意义数据 | `Program.s` 里还有默认 `printh` | 删除上电 `printh` |
| 点调频按钮就发串口 | 把输出脚本粘到了步进按钮 | 只有 `b32` 可以发业务帧 |
| 1Hz 点 +100 变 101Hz | 没有先按步长向下对齐 | 使用本文的步进脚本 |
| 波形多个同时高亮 | 只画了当前按钮，没重绘同一路另外两个按钮 | 每次选择后粘贴整段 A/B 高亮片段 |
| 负相位发送错 | 直接 `prints b_phase,2` | 先 `phase_send=65536+b_phase` 再发送 |
