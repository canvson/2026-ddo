# 串口屏验收清单

## 1. 静态文件

- [ ] `双路波形控制.HMI` 位于 `.电赛预备/屏控波形输出串口屏部分/`。
- [ ] 页面只使用 `page0` 作为业务页。
- [ ] `Program.s` 中 `baud=115200`。
- [ ] `Program.s` 中没有默认上电 `printh`。
- [ ] 工程包含 `ID0.zi`、`ID1.zi` 或至少一个可显示中文和数字的字库。

## 2. HMI 编译

- [ ] USART HMI 编辑器能打开工程。
- [ ] 编译结果为 `0错误、0警告`。
- [ ] 能导出 `.tft`。

## 3. UI 行为

- [ ] A 路正弦/方波/三角互斥高亮。
- [ ] B 路正弦/方波/三角互斥高亮。
- [ ] A 路波形选择不影响 B 路高亮状态。
- [ ] B 路波形选择不影响 A 路高亮状态。
- [ ] 频率、幅值、占空比、相位调整后本地数值立即变化。
- [ ] 返回按钮不发送业务帧。

## 4. 串口抓包

- [ ] 上电后不出现 `AA 21 16`。
- [ ] 点击波形按钮不出现 `AA 21 16`。
- [ ] 调频按钮不出现 `AA 21 16`。
- [ ] 调幅按钮不出现 `AA 21 16`。
- [ ] 调占空比按钮不出现 `AA 21 16`。
- [ ] 调相位按钮不出现 `AA 21 16`。
- [ ] 只有点击“应用并输出”时出现一帧 `AA 21 16 ... CHECK 55`。

## 5. 参数边界

- [ ] A 频率输入 `0` 或连续递减后，最终不低于 `1Hz`。
- [ ] B 频率输入 `30000000` 后输出，最终按 `20000000Hz` 发送。
- [ ] 幅值低于 0 时回到 `0mVpp`。
- [ ] 幅值高于 5000 时回到 `5000mVpp`。
- [ ] 占空比低于 10 时回到 `10%`。
- [ ] 占空比高于 90 时回到 `90%`。
- [ ] 占空比非 5 的整数倍时向下吸附到 5% 步进。
- [ ] 相位低于 -180 时回到 `-180deg`。
- [ ] 相位高于 180 时回到 `180deg`。

## 6. 频率步进

- [ ] `1Hz +100Hz => 100Hz`。
- [ ] `1Hz +1KHz => 1000Hz`。
- [ ] `1Hz +10KHz => 10000Hz`。
- [ ] `1Hz +100KHz => 100000Hz`。
- [ ] `1Hz +1MHz => 1000000Hz`。
- [ ] `1001Hz +1KHz => 2000Hz`。
- [ ] `1001Hz -1KHz => 1Hz`。
- [ ] `20000001Hz +1MHz` 经过限幅后不超过 `20000000Hz`。

## 7. STM32 对接

- [ ] STM32 USART1 使用 `115200 8N1`。
- [ ] STM32 USART1 RX 使用 DMA。
- [ ] STM32 能解析 22 字节 `DATA`。
- [ ] STM32 按 `int16_t` 解析 `phase_b_rel_a_deg`。
- [ ] STM32 校验失败时不更新输出。
- [ ] STM32 输出后回写屏幕当前采用的参数。
