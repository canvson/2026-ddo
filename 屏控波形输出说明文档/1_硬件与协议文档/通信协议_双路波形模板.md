# HMI、STM32 与 FPGA 通信协议

串口屏只连接 STM32，不直接连接 FPGA。固定链路为：串口屏发送 `AA 21 16` 双路配置帧，STM32 校验并换算为 DDS 参数，再通过 USART2 向 FPGA 发送 `A5 41 1C` 简短二进制帧。FPGA 不做状态回传。

## 物理层

### HMI -> STM32

| 项目 | 配置 |
|---|---|
| 串口 | USART1 |
| 波特率 | 115200 |
| 数据格式 | 8 数据位，1 停止位，无校验 |
| 连接 | HMI TX 接 STM32 RX，HMI RX 接 STM32 TX，共地 |
| STM32 接收 | 必须使用 DMA |

### STM32 -> FPGA

| 项目 | 配置 |
|---|---|
| 串口 | USART2 |
| 波特率 | 115200 |
| 数据格式 | 8 数据位，1 停止位，无校验 |
| 连接 | STM32 TX 接 FPGA UART RX，共地 |
| FPGA 回传 | 不使用 |

## HMI -> STM32 帧格式

```text
AA CMD LEN DATA CHECK 55
```

| 字段 | 长度 | 说明 |
|---|---:|---|
| `AA` | 1 | 帧头 |
| `CMD` | 1 | 命令字 |
| `LEN` | 1 | `DATA` 字节数 |
| `DATA` | LEN | 命令数据 |
| `CHECK` | 1 | `(AA + CMD + LEN + 所有 DATA 字节) & 0xFF` |
| `55` | 1 | 帧尾 |

所有多字节整数均为小端序。

### 命令表

| CMD | LEN | 名称 | 方向 | 用途 |
|---:|---:|---|---|---|
| `0x21` | `0x16` | `OUTPUT_CONFIG` | HMI -> STM32 | 应用当前 A/B 参数并输出 |

本模板不再使用 `SET_CONFIG`。调节参数过程只改 HMI 本地变量，不发串口业务帧。

### `OUTPUT_CONFIG` 数据区

`DATA` 固定 22 字节：

| 偏移 | 字段 | 类型 | 说明 |
|---:|---|---|---|
| 0 | `proto_ver` | `uint8` | 固定 `1` |
| 1 | `flags` | `uint8` | bit0=A 使能，bit1=B 使能，默认 `0x03` |
| 2 | `wave_a` | `uint8` | 0 正弦，1 方波，2 三角 |
| 3 | `freq_a_hz` | `uint32` | A 频率，1~20000000 Hz |
| 7 | `amp_a_mVpp` | `uint16` | A 峰峰值，0~5000 mVpp |
| 9 | `duty_a_pct10` | `uint16` | A 占空比，0.1% 单位，500=50.0% |
| 11 | `wave_b` | `uint8` | 0 正弦，1 方波，2 三角 |
| 12 | `freq_b_hz` | `uint32` | B 频率，1~20000000 Hz |
| 16 | `amp_b_mVpp` | `uint16` | B 峰峰值，0~5000 mVpp |
| 18 | `duty_b_pct10` | `uint16` | B 占空比，0.1% 单位，500=50.0% |
| 20 | `phase_b_rel_a_deg` | `int16` | B 相对 A 相位，-180~180 deg |

### 参数边界

| 参数 | 范围 | HMI 处理 | STM32 处理 |
|---|---:|---|---|
| `wave_a/wave_b` | 0~2 | 按钮互斥选择 | 超界拒收 |
| `freq_a_hz/freq_b_hz` | 1~20000000 | 输出前限幅 | 超界拒收 |
| `amp_a_mVpp/amp_b_mVpp` | 0~5000 | 输出前限幅 | 超界拒收 |
| `duty_a_pct10/duty_b_pct10` | 100~900 | HMI 用 10~90%，发送前乘 10 | 超界拒收 |
| `phase_b_rel_a_deg` | -180~180 | 输出前限幅，负数按二进制补码发送 | 超界拒收 |

### 示例帧

默认参数：A=正弦 1000Hz/1000mVpp/50%，B=正弦 1000Hz/1000mVpp/50%，相位 0deg：

```text
AA 21 16 01 03 00 E8 03 00 00 E8 03 F4 01 00 E8 03 00 00 E8 03 F4 01 00 00 7B 55
```

A=正弦 500Hz/1000mVpp/50%，B=方波 1000Hz/2000mVpp/30%，B 滞后 A 60deg：

```text
AA 21 16 01 03 00 F4 01 00 00 E8 03 F4 01 01 E8 03 00 00 D0 07 2C 01 3C 00 E6 55
```

边界测试：A=方波 1Hz/0mVpp/10%，B=三角 20MHz/5000mVpp/90%，B 超前 A 180deg：

```text
AA 21 16 01 03 01 01 00 00 00 00 00 64 00 02 00 2D 31 01 88 13 84 03 4C FF 19 55
```

### STM32 解析要求

STM32 必须检查：

- 帧头必须为 `0xAA`，帧尾必须为 `0x55`。
- `CMD` 必须为 `0x21`。
- `LEN` 必须为 `0x16`。
- `CHECK` 必须匹配低 8 位累加和。
- 所有参数必须在范围内；任意错误都不更新输出。
- 成功接收后先整体替换 A/B 配置，再换算并下发 FPGA 帧。

## STM32 -> FPGA 帧格式

```text
A5 41 1C DATA CHECK 5A
```

| 字段 | 长度 | 说明 |
|---|---:|---|
| `A5` | 1 | 帧头 |
| `41` | 1 | 双路 DDS 配置命令 |
| `1C` | 1 | `DATA` 固定 28 字节 |
| `DATA` | 28 | FPGA 可直接使用的 DDS 参数 |
| `CHECK` | 1 | `(A5 + 41 + 1C + 所有 DATA 字节) & 0xFF` |
| `5A` | 1 | 帧尾 |

### FPGA `DATA` 数据区

| 偏移 | 字段 | 类型 | 说明 |
|---:|---|---|---|
| 0 | `proto_ver` | `uint8` | 固定 `1` |
| 1 | `flags` | `uint8` | bit0=A 使能，bit1=B 使能 |
| 2 | `wave_a` | `uint8` | 0 正弦，1 方波，2 三角 |
| 3 | `fword_a` | `uint32` | A 路 32bit DDS 频率字，小端 |
| 7 | `amp_a_q13` | `uint16` | A 路幅值系数，`5000mVpp -> 8192` |
| 9 | `duty_a_q32` | `uint32` | A 路方波占空比阈值，`50% -> 0x80000000` |
| 13 | `wave_b` | `uint8` | 0 正弦，1 方波，2 三角 |
| 14 | `fword_b` | `uint32` | B 路 32bit DDS 频率字，小端 |
| 18 | `amp_b_q13` | `uint16` | B 路幅值系数，`5000mVpp -> 8192` |
| 20 | `duty_b_q32` | `uint32` | B 路方波占空比阈值 |
| 24 | `phase_b_q32` | `uint32` | B 相对 A 的 32bit 相位偏移 |

### STM32 换算规则

| HMI 参数 | FPGA 参数 | 换算 |
|---|---|---|
| `freq_hz` | `fword` | `round(freq_hz * 2^32 / 125000000)` |
| `amp_mVpp` | `amp_q13` | `round(amp_mVpp * 8192 / 5000)` |
| `duty_pct10` | `duty_q32` | `round(duty_pct10 * 2^32 / 1000)` |
| `phase_deg` | `phase_b_q32` | 负角度先加 360，再 `round(deg * 2^32 / 360)` |

FPGA 端使用 `phase_acc_b - phase_b_q32` 取样，因此 HMI 约定保持为：正角度表示 B 滞后 A，负角度表示 B 超前 A。B 相位只在 A/B 同频时具有稳定“相对相位”意义；不同频率时它只是 B 路初始相位偏移。20MHz 允许输出，但正弦/三角在 125MHz DDS 时钟下采样点数较少，波形质量以实际 DAC 和模拟链路为准。
